# AI SEO Page Refresh Checklist

Use this before publishing or refreshing any canonical AI SEO page.

## Required Page Elements

| Check | Pass |
|---|---|
| One primary query and one canonical target URL are clear. |  |
| H1 matches the query intent without keyword stuffing. |  |
| Intro answers the query directly in the first 100-150 words. |  |
| Direct Answer block is self-contained and roughly 40-60 words. |  |
| Page has a current `updatedAt` date only if content materially changed. |  |
| Author is `StashDog Editorial Team` with Dogfood Lab LLC attribution. |  |
| At least three internal links point to next-step or supporting pages. |  |
| Pricing claims link to `/pricing/` or `/pricing.md`. |  |
| App availability claims link to download or app-store surfaces. |  |
| Factual external claims have source links. |  |
| No claim conflicts with `/pricing.md` or current product limits. |  |

## Extractability Checks

| Check | Pass |
|---|---|
| Page includes FAQ with natural-language questions. |  |
| Comparison intent uses a table. |  |
| How-to intent uses ordered steps and HowTo schema where relevant. |  |
| Listicle/category intent uses ItemList schema where relevant. |  |
| Paragraphs are short enough to be quoted or summarized cleanly. |  |
| Important claims work without surrounding context. |  |

## Technical Checks

| Check | Pass |
|---|---|
| Canonical URL is absolute and ends with trailing slash. |  |
| Page declares `index,follow`. |  |
| Page has Article schema. |  |
| Page has BreadcrumbList schema. |  |
| FAQPage schema is present when FAQ content exists. |  |
| `/llms.txt` and `/pricing.md` alternate links appear in page head. |  |
| Page appears in sitemap after build. |  |
| No noindex URL appears in sitemap. |  |
